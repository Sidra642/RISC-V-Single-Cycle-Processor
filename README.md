# RISC-V-Single-Cycle-Processor
Overview

This project implements a single-cycle RISC-V CPU based on the RV32I base integer instruction set. In a single-cycle design, fetch, decode, execute, memory access, and write-back all happen within one clock period. The design is simple and easy to verify, which makes it a good foundation for learning computer architecture and for later extending into a pipelined core.
